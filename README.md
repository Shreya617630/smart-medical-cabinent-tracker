# Smart Medicine Cabinet Tracker
IoT-based medicine expiry monitoring system using Arduino Uno R3.

## Features
- RFID-based medicine identification
- Real-time expiry computation via DS1307 RTC
- DHT22 environmental monitoring (temp + humidity)
- Three-tier alert system (SAFE / WARNING / CRITICAL)
- Dose tracking and caregiver JSON notification stream

## Hardware
Arduino Uno R3, MFRC522 RFID, DS1307 RTC, DHT22, LCD 16x2, 4x4 Keypad
